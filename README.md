# 🌙 Luna Development Website

A modern personal portfolio website for **Luna Development**, showcasing software engineering, web development, and Minecraft development projects.

---

## 🚀 Features

- Responsive landing page design
- Modern dark gradient UI
- Glassmorphism-style project cards
- Open Graph support (Discord / Facebook / iMessage embeds)
- Twitter/X rich link previews
- Simple interactive buttons
- Clean, beginner-friendly HTML + CSS structure

---

## 🧰 Built With

- HTML5
- CSS3
- Vanilla JavaScript (minimal usage)
